Supports inline Markdown. icon - optional Material Symbols Outlined name, for example "download". icon_filled - optional boolean. Set to true for filled icons. Defaults to false. badge - optional short label shown next to the title, for example "Deprecated". badge_level - optional alert level for the badge: "note", "warning", or "danger". Defaults to "warning".
