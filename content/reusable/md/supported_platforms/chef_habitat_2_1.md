Chef Habitat 2.1 has the following minimum platform requirements:

| Platform | Architecture                            | Supported Version                                |
| -------- | --------------------------------------- | ------------------------------------------------ |
| Linux    | x86_64 (64-bit Intel or AMD)            | Modern Linux kernels                             |
| Linux    | ARM64 (64-bit)                          | Modern Linux kernels                             |
| Windows  | x86_64 (64-bit)                         | Windows Server 2012 or later; Windows 8 or later |
| macOS    | Apple Silicon (ARM64) or Intel (x86_64) | macOS 14 or later                                |
