Chef Workstation 26.2 is supported on the following platforms:

| Platform | Architecture                    | Supported Versions                                                                                      |
| -------- | ------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Linux    | x86_64 (amd64), ARM64 (aarch64) | Currently supported RPM-based and Debian-based Linux distributions running Linux kernel 2.6.32 or later |
| Windows  | x86_64 (64-bit)                 | Windows 10 or later; Windows Server 2016 or later                                                       |
| macOS    | ARM64 (Apple Silicon)           | macOS 14 (Sonoma) and later                                                                             |
