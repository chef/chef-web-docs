| Operating System                  | Supported Versions        |
| --------------------------------- | ------------------------- |
| Red Hat Enterprise Linux (64-bit) | 7, 8, 9                   |
| Ubuntu (64-bit)                   | 16.04.x, 18.04.x, 20.04.x |
| CentOS (64-bit)                   | 7                         |
| Amazon Linux 2 (64-bit)           | 2 (kernel 5.10)           |
| SUSE Linux Enterprise Server      | 12.5                      |
| Oracle Linux                      | 9                         |

Additional requirements:

- On RHEL 8 and RHEL 9, SELinux must be configured in permissive mode.
