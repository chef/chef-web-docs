Chef Habitat 1.6 has the following minimum platform requirements:

| Platform | Architecture    | Minimum Version                                  |
| -------- | --------------- | ------------------------------------------------ |
| Linux    | x86_64 (64-bit) | Linux kernel 2.6.32 or later                     |
| macOS    | x86_64 (64-bit) | macOS 10.9 or later                              |
| Windows  | x86_64 (64-bit) | Windows Server 2012 or later; Windows 8 or later |
